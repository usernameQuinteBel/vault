# React

> Een JavaScript-bibliotheek om een UI uit **herbruikbare componenten** te bouwen; in dit vak de **View** bij de .NET-API.

## Vier ideeën
1. **Razendsnelle DOM-manipulatie**: React houdt een **virtual DOM** bij, vergelijkt die met de echte DOM en past enkel de verschillen toe.
2. **Samenstelbare UI**: modulair, compact, zelfstandig ([[Component]]).
3. **Visuals volledig in JavaScript** ([[JSX]]).
4. **Enkel de V in MVC**: Model en Controller zijn vrij (bij ons de .NET API, [[MVC]]).

Andere frameworks: Vue.js, Angular. React wordt o.a. gebruikt door Netflix, Airbnb, Dropbox, Atlassian, The New York Times.
