# ORM

> Een **Object-Relational Mapper** laat je gegevens opvragen en wijzigen met objecten, **zonder SQL te schrijven**.

| Relationele database (SQL Server) | Object-georiënteerd (C#) |
|---|---|
| SQL-queries | C#-methodes op objecten |
| Tabellen | klassen → [[DbSet]]s (collecties) |
| Rijen | getypeerde objecten |
| Kolommen | getypeerde properties |
| Joins | [[Navigation property|navigation properties]] ([[Include en loading|Include]]) |

Voorbeeld in dit vak: [[Entity Framework Core]].
