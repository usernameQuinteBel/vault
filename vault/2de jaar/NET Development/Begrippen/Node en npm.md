# Node en npm

> **Node.js** voert JavaScript buiten de browser uit en levert **npm**, de pakketbeheerder voor JavaScript (zoals [[NuGet]] voor .NET).

- Installeren via nodejs.org; controleer met `node -v` en `npm -v`.
- Pakketten: `npm install react-router-dom`, `npm install axios`, `npm install @auth0/auth0-react`.
- Dev-server starten: `npm run dev` (Ctrl-C om te stoppen).
