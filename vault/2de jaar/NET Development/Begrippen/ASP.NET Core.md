# ASP.NET Core

> Het **open-source, cross-platform .NET-framework** om webapps, services, IoT-apps en mobiele back ends te bouwen; in dit vak gebruikt voor een **Web API met controllers**.

| Punt | Details |
|---|---|
| Draait op | het .NET-platform ([[Het .NET-platform]]) |
| Ontwikkelen | Windows, Linux, macOS, Docker |
| Deployen | cloud of on-premise (ideaal voor Docker-containers) |
| Herkomst | open-source herontwerp van ASP.NET (eerste release **2016**) |
| Versie in de cursus | **.NET 10.0 (LTS)** |

## Twee manieren om een API te bouwen
| Aanpak | Kenmerk |
|---|---|
| **MVC (controllers)** | volledig; **dit gebruiken we** ([[MVC]], [[Controller]]) |
| **Minimal API** | sneller en lichter, minder features |
