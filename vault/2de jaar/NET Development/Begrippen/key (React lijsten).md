# key (React lijsten)

> Een **unieke `key`** op elk element van een gegenereerde lijst laat React elementen onderscheiden.

Zonder key: *"Warning: Each child in a list should have a unique "key" prop."*
- Gebruik bij voorkeur een **id** (`key={student.id}`); een index kan ook.
- Zet de key op het element dat je in `map` teruggeeft ([[Lijsten renderen met map]]).
