# Groepsopdracht 3 - Lo-fi prototype 🧩

> Werk minstens één belangrijke user flow uit tot een **klikbaar, testbaar lo-fi prototype** in Figma, gebaseerd op je analyses. Volgende les test je het bij echte gebruikers.

## Stappen
1. Nieuw **Figma Design file** in je teamproject (lo-fi op een eigen **page**).
2. Kies minstens **één** belangrijke [[User flow]] (aantal hangt af van de complexiteit; vraag de docent bij twijfel). Teken eerst de **gewenste** flow (future state) naast de current-state flow uit deel 1.
3. Elke stap wordt een **frame** (mobiel of desktop, consistent).
4. Bouw de schermen als [[Wireframe|wireframes]] — herhaalde elementen (navbar, kaart, knop) als **componenten**, schikken met [[Auto Layout]].
5. **Prototype**-tab: connections (On tap → Navigate to), een **starting point** per flow, Back-acties.
6. Maak waar relevant **varianten** van een scherm (bv. filter als zijpaneel vs. bottom sheet) om ze te testen.
7. Laat **niet-uitgewerkte onderdelen** staan met een notitie ("hier komt de bevestigingsmail") — tenzij bewust geschrapt.

## Baseer je op
| Analyse | Gebruik |
|---|---|
| [[User journey map]] | elk pijnpunt → een ontwerpbeslissing |
| [[User flow]] (current state) | waar kunnen stappen weg of samen? |
| [[Heuristische evaluatie|UX-analyse]] | rode stickies oplossen, groene behouden |

## Regels voor lo-fi
Grijstinten · max. 2 fonts · rechthoeken met kruis voor media · **echte, betekenisvolle tekst** · geen animaties (Instant) · intentie noteren. Zie [[Wireframe]] en [[Lo-fi en hi-fi]].

## Klaar om te testen?
- [ ] De taak uit je testplan is **volledig doorklikbaar** van start tot eind.
- [ ] Geen doodlopende schermen (altijd een weg terug, H3).
- [ ] Knoppen en labels zijn begrijpelijk zonder uitleg.
- [ ] Startpunt staat juist in Present mode.
