# Figma

> Het ontwerpprogramma van het vak: in de browser of als app, samenwerken in real time. Je hebt een **Figma Education account** nodig.

## Wat gebruik je ervan in dit vak?
| Functie | Waarvoor | Zie |
|---|---|---|
| Frames | Eén scherm (mobiel, desktop) | [[Wireframe]] |
| Prototype-modus | Schermen klikbaar verbinden, testen in **Present mode** | [[Prototype]] |
| Auto Layout | Vaste padding en gap volgens je spacing-schaal | [[Auto Layout]] |
| Layout guides | Kolommen, marges, gutters | [[Layout grid]] |
| Text styles | Typescale vastleggen | [[Typescale]] |
| Variables | Kleuren als primitives en tokens | [[Design tokens]] |
| Components & variants | Herbruikbare knoppen, velden met states | [[Component set en varianten]] |
| Annotation tool (Shift+T) | Notities voor developers: labels, alt-tekst, koppen | [[Accessibility-annotaties]] |
| Plugins | Color Blind, Stark (contrast), typescale | [[Kleurcontrast]] |
| Pages | Lo-fi, hi-fi en design system gescheiden houden | [[Design system]] |

## Projectstructuur in de groepsopdracht
1. Eén groepslid maakt een **project** aan in het Figma-team van de klas, met de groepsnaam als projectnaam.
2. Via **Share** nodigt hij de andere groepsleden uit met **edit**-rechten.
3. De toegang voor het klasteam zet je op **view-only**.
4. In het project maak je [[FigJam]]-borden (analyse) en Figma Design files (ontwerp).

## Handige sneltoetsen
- `Ctrl/⌘ + Alt + K`: component maken
- `Ctrl/⌘ + D`: dupliceren
- `Ctrl/⌘ + K`: Actions-zoekbalk (plugins zoeken)
- `C`: comment · `Shift + T`: annotatie
