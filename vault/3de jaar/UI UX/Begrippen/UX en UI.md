# UX en UI

> **UX (User Experience)** is hoe het voelt om een product te gebruiken: vind ik wat ik zoek, lukt mijn taak, waar erger ik me? **UI (User Interface)** is de visuele laag waarmee je dat doet: knoppen, kleuren, typografie, layout.

## Het verschil
| | UX | UI |
|---|---|---|
| Vraag | Werkt het voor de gebruiker? | Hoe ziet het eruit? |
| Gaat over | Flows, structuur, logica, pijnpunten | Hiërarchie, kleur, typografie, spacing |
| Methodes | Gebruikersonderzoek, [[User journey map]], [[User flow]], [[User testing]] | [[Visuele hiërarchie]], [[Kleursysteem]], [[Typescale]], [[Design system]] |

## Ze horen samen
| UI | UX | Resultaat |
|---|---|---|
| Mooi | Slecht | Frustratie: het ziet er goed uit maar je raakt nergens |
| Lelijk | Goed | Bruikbaar, maar niet aantrekkelijk |
| Goed | Goed | Succes |

> *"Design isn't just what it looks like and feels like — design is how it works."* — Steve Jobs

## Voor developers
Je bouwt geen features maar ervaringen. Elk project wordt mee beoordeeld op de interface, en je moet keuzes van een designer kunnen begrijpen en in code omzetten (zie [[Design tokens]]).
