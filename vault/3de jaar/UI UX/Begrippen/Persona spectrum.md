# Persona spectrum

> Een denkkader uit **Microsoft Inclusive Design**: een beperking kan **permanent**, **tijdelijk** of **situationeel** zijn. Wat je ontwerpt voor mensen met een permanente beperking, helpt **veel meer mensen**.

## Het spectrum
| Vermogen | Permanent | Tijdelijk | Situationeel |
|---|---|---|---|
| **zicht** | blind of slechtziend | na een oogoperatie | fel zonlicht op je scherm |
| **motoriek** | één arm | gebroken arm | baby op je arm |
| **gehoor** | doof | oorontsteking | lawaaierige trein |
| (spraak) | geen spraak | laryngitis | zwaar accent / buitenland |

## Wat betekent dit voor je ontwerp?
| Ontwerpkeuze | Helpt |
|---|---|
| hoog **contrast** | slechtzienden én iedereen in de zon |
| grote **klikzones** (≥ 44 px), bediening met één hand | één arm, gebroken arm, baby op de arm |
| **ondertitels** bij video | doven én pendelaars zonder koptelefoon |
| info **niet enkel via kleur** | kleurenblinden én slechte schermen |
| duidelijke **labels** | screen reader-gebruikers én vermoeide gebruikers |

## De boodschap
Accessibility is **geen randgeval** voor een kleine groep: iedereen heeft weleens een (tijdelijke of situationele) beperking. Daarom is het deel van goede UX.
