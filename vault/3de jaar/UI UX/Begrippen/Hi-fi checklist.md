# Hi-fi checklist

> De controlelijst uit de les **UI Principes**: overloop dit vóór je je hi-fi ontwerp indient. **Elk vinkje is een principe** uit het hoofdstuk.

| Check | Vraag | Principe |
|---|---|---|
| ☐ **Hiërarchie** | Squint test: valt het belangrijkste meteen op? | [[Visuele hiërarchie]] · [[Squint test]] |
| ☐ **Spacing** | Komt elke afstand uit je 4/8-schaal (geen 13 of 27 px)? | [[Spacing system]] |
| ☐ **Uitlijning** | Delen elementen dezelfde randen? Staat je layout grid aan? | [[Uitlijning]] · [[Layout grid]] |
| ☐ **Typografie** | Max. 2 fonts; gebruikt **alle** tekst een text style uit je typescale? | [[Typescale]] · [[Typografie in UI]] |
| ☐ **Kleur** | Komt elke kleur uit je kleursysteem (variabelen), geen losse hex-codes? | [[Kleursysteem]] |
| ☐ **Kleurverhouding** | Domineert neutraal, accentkleur spaarzaam? | [[60-30-10 regel]] |
| ☐ **Consistentie** | Ziet wat hetzelfde doet er hetzelfde uit? Componenten gebruikt? | [[Gestaltprincipes]] (gelijkenis) |
| ☐ **Structuur** | Staan lo-fi en hi-fi op aparte pages? | |

## Hoe controleer je snel in Figma?
- **Spacing**: selecteer een element en hou **Alt** ingedrukt → je ziet de afstanden tot de buren.
- **Losse kleuren/fonts**: selecteer het frame → rechterpaneel *Selection colors* en tekststijlen; alles moet een **naam** (variabele/style) tonen, geen hex of "Mixed".
- **Componenten**: losgekoppelde kopieën (*detached*) hebben geen ◇-icoon in de lagenlijst.

## Wat komt daarna?
De volgende les controleer je ook **accessibility** (contrast, states, labels) en leg je alles vast als [[Design system]] → zie de checklist in [[Design system documenteren]].
