# WCAG

> **Web Content Accessibility Guidelines**: de internationale richtlijnen voor digitale toegankelijkheid (W3C). Huidige versie **WCAG 2.2**, met drie niveaus: **A** (minimum), **AA** (wat wetten vragen), **AAA** (strengst).

## De 4 principes: P.O.U.R.
| | Principe | Betekenis | Voorbeelden |
|---|---|---|---|
| **P** | Perceivable | Waarneembaar | Contrast, alt-tekst, ondertitels |
| **O** | Operable | Bedienbaar | Toetsenbord, zichtbare focus, genoeg tijd |
| **U** | Understandable | Begrijpelijk | Duidelijke labels, voorspelbaar gedrag, foutmeldingen |
| **R** | Robust | Robuust | Werkt op verschillende devices, browsers, hulpmiddelen |

## De cijfers voor niveau AA (moet je kennen!)
| Wat | Norm | Toelichting |
|---|---|---|
| Contrast gewone tekst | **4,5 : 1** | Tekst t.o.v. achtergrond. #767676 op wit haalt het net. |
| Contrast grote tekst | **3 : 1** | Vanaf 24 px (of 18,7 px bold). Bv. #949494 op wit. |
| Contrast UI-elementen | **3 : 1** | Geen tekst maar wel informatie: iconen, rand van een invoerveld, focusrand. |
| Klikzone | **24 × 24 px** minimum | Voor vingers liefst **44–48 px**. |
| Zoom | **200 %** | Tekst dubbel zo groot zonder overlap of afgeknipte tekst: plan ruimte in. |

**Uitzonderingen** op contrast: uitgeschakelde (disabled) elementen, logo's en puur decoratieve elementen.
