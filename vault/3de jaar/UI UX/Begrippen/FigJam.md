# FigJam

> Het **online whiteboard** van Figma: een oneindig canvas om **samen** te brainstormen, te analyseren en te plannen met stickies, vormen, verbindingslijnen en widgets. Geen tool om schermen te ontwerpen — daarvoor is [[Figma]] (Design).

## Waarvoor in dit vak?
| Opdracht | FigJam-gebruik |
|---|---|
| [[Groepsopdracht 1 - Gebruikersanalyse]] | scenario's, [[User journey map|journey maps]], [[User flow|user flows]], Photo Booth-widget voor teamfoto's |
| [[Groepsopdracht 2 - UX-analyse]] | screenshots + gekleurde stickies per heuristiek |
| [[Groepsopdracht 4 - User testing]] | testresultaten bundelen (groen/rood/blauw) |
| [[Groepsopdracht 5 - Moodboard en hi-fi ontwerp]] | inspiratie verzamelen voor het [[Moodboard]] |
De docent gebruikt FigJam ook voor **klassikale borden** en oefeningen.

## Handige functies
| Functie | Sneltoets / waar |
|---|---|
| sticky note | **S** (kleur kiezen = betekenis geven) |
| vormen (cirkel, ruit, pil) voor flows | **R** / shapes-menu |
| verbindingslijn (connector) | **X** — blijft vast aan vormen als je ze verplaatst |
| sectie (groeperen) | **Shift + S** |
| comment | **C** |
| stempels en emoji-reacties | **E** |
| widgets & templates | toolbar (bv. Photo Booth, timer, stemmen) |
| timer en "voting" | om in groep keuzes te maken |

## Tips
- Spreek **kleurcodes** af (groen/rood/blauw) en zet een **legende** op het bord.
- Gebruik **secties** per opdrachtdeel, zodat het bord leesbaar blijft.
- Templates mogen, maar focus op de **inhoud**.
