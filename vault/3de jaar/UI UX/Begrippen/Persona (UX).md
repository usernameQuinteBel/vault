# Persona (UX)

> Een **fictief maar realistisch profiel** van een typische gebruiker, gebaseerd op onderzoek. Een persona helpt het team om te ontwerpen voor **iemand concreet** in plaats van voor "de gebruiker".

## Wat staat erin?
| Onderdeel | Voorbeeld |
|---|---|
| naam + foto | *Sam, 20* |
| achtergrond/rol | student 3APP, pendelt met de bus |
| doelen | snel een studieruimte reserveren voor groepswerk |
| frustraties | te veel klikken op de gsm, geen overzicht van vrije lokalen |
| context/gedrag | gebruikt vooral zijn smartphone, tussen lessen, weinig tijd |
| digitale vaardigheid | hoog |
| quote | "Ik wil gewoon zien wat nú vrij is." |

## Persona vs. scenario
| Persona | [[Gebruiksscenario]] |
|---|---|
| **wie** is de gebruiker | **wat** probeert die in een specifieke situatie te doen |
| algemeen profiel | één concrete taak met context en constraints |
Een scenario hangt aan een persona: *Sam* + *"binnen een uur een ruimte nodig"*.

## Goede persona's
- Gebaseerd op **bewijs** (observaties, gesprekken, reviews), niet op clichés.
- **Weinig** persona's (1–3) die echt verschillen in doelen of gedrag.
- Gebruik ze actief: "Zou Sam dit vinden?" — bv. bij de [[Heuristische evaluatie]].
