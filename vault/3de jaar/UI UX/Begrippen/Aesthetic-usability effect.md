# Aesthetic-usability effect

> Gebruikers ervaren **esthetisch aantrekkelijke** ontwerpen als **bruikbaarder** — ook als ze dat objectief niet zijn. (Kurosu & Kashimura, 1995; een van de [[Laws of UX]].)

## Wat betekent dat?
- Mensen zijn **toleranter** voor kleine problemen in een mooie interface.
- Een verzorgde UI wekt **vertrouwen** (belangrijk bij bank-apps, webshops).
- Daarom zegt de les: goede UI + goede UX = succes; mooie UI + slechte UX = toch frustratie op termijn.

## Het gevaar bij testen
Omdat mooi als bruikbaar aanvoelt, kunnen testers bij een hi-fi prototype **problemen niet melden** ("ziet er goed uit!"). Daarom:
- **Test vroeg in lo-fi** ([[Lo-fi en hi-fi]]): dan gaat de feedback over de flow.
- **Observeer gedrag, geen meningen** ([[User testing]]): kijk of iemand de taak **kan**, niet of hij het **mooi** vindt.

## Voor jou als developer
Een afgewerkte UI is geen luxe: ze beïnvloedt hoe je app beoordeeld wordt (ook in projecten en op examens). Maar ze vervangt geen goede flow.
