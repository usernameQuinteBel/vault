# Squint test

> Een snelle test voor [[Visuele hiërarchie]]: **knijp je ogen half dicht** (of vervaag het scherm) en kijk wat er nog opvalt. Valt het belangrijkste element nog op? Dan klopt je hiërarchie.

## Hoe doe je het?
1. Bekijk je scherm op normale grootte.
2. Knijp je ogen half dicht tot tekst onleesbaar wordt — je ziet enkel nog **vlakken, contrasten en groottes**.
3. Vraag je af:
   - Wat zie ik **eerst**? Is dat de belangrijkste info/actie?
   - Valt de **primaire knop** op?
   - Zie ik duidelijke **groepen** (kaarten, secties)?
4. Alternatief: een **blur** van 4–8 px op een kopie van je frame in Figma, of het scherm van ver bekijken.

## Wat als het faalt?
| Probleem | Oplossing |
|---|---|
| alles even zwaar | grootteverschil vergroten via je [[Typescale]] |
| actie valt niet op | accentkleur enkel voor die actie ([[60-30-10 regel]]) |
| geen groepen zichtbaar | meer witruimte tussen groepen ([[Spacing system]]) |
| verkeerd element springt eruit | contrast of kleur van dat element dempen |
