# Microsoft Entra ID

> Microsofts dienst voor identiteit en toegang (vroeger *Azure Active Directory*): wie ben je, hoe meld je aan en waar heb je recht op?

## Wat beheert het?
- Gebruikersaccounts, groepen en rollen van de [[Tenant]].
- Aanmelden (single sign-on, MFA).
- Beleid voor toegang (conditional access).

## Waarom relevant?
- Power Apps zijn "veilig by default" omdat aanmelden via Entra ID loopt.
- [[Microsoft 365 Copilot]] en [[Microsoft Graph]] respecteren het beleid dat in Entra ID staat.
