# Site columns

> Een site column is een herbruikbare kolomdefinitie die je aan meerdere lijsten en bibliotheken kan toewijzen.

## Waarom?
Stel dat veel lijsten dezelfde kolom nodig hebben, bv. *Actief/Inactief* of *Afdeling*. In plaats van die telkens opnieuw te maken (met kans op verschillen), maak je één **site column**. Zo krijg je **consistente** instellingen over alle lijsten heen.

## Hoe?
1. **Site settings → Web Designer Galleries → Site columns**.
2. Veel gangbare kolommen bestaan al; je kan ook een eigen kolom maken.
3. In **List settings** van een lijst voeg je de site column toe ("Add from existing site columns").
