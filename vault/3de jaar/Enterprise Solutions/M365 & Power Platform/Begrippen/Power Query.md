# Power Query

> De tool om data uit externe bronnen op te halen, op te kuisen en te transformeren voor je ze inlaadt – in Dataverse, Excel, Power BI, ...

## Gebruik in Dataverse
1. Tabel → **Import → Import data**.
2. Kies een connector (Excel workbook, SharePoint, SQL, Salesforce, ...).
3. Blader naar het bestand (bv. `DronesManufacturers.xlsx` in OneDrive).
4. **Transform**: bv. *Use first row as headers*, kolommen hernoemen, types instellen.
5. Kolommen **mappen** naar de Dataverse-kolommen en laden.

## Merge
Om data samen te voegen met bestaande rijen heb je **sleutels** nodig in bron en bestemming.
