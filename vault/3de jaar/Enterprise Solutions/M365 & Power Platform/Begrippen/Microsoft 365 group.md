# Microsoft 365 group

> Een groep in Microsoft 365 die het lidmaatschap van een team of site bewaart en daarmee de toegang regelt tot alle gedeelde teamtools: SharePoint-site, gedeelde mailbox, agenda, Planner, ...

## Wat zit er bij een M365-groep?
- Een **gedeelde mailbox** en **agenda** (in Outlook onder *Groups*, of in de site via *Conversations*).
- Een **SharePoint-site** (bestanden).
- Een **Planner**-plan, OneNote, ...
- Eventueel een **Team** in Microsoft Teams.

## Rollen
| Rol | Rechten |
|---|---|
| **Owners** (eigenaars) | Volledige controle |
| **Members** (leden) | Bewerken |
| **Visitors** (bezoekers) | Enkel lezen |

Je voegt mensen per categorie toe in het [[Microsoft 365 admin center]]; de rechten zie je terug in de SharePoint-site.

## Wanneer wordt ze automatisch aangemaakt?
- Bij een **[[Team site]]**.
- Bij een **team** in Microsoft Teams.
- **Niet** bij een [[Communication site]].

## Tip uit de les
Standaard kunnen eigenaars/leden niet mailen **namens** de groep (bv. als *helpdesk@...*). Dat stel je in via het **Exchange admin center** (groepen → delegates / send as).
