# Document library

> Een bibliotheek in SharePoint is een lijst voor **bestanden**: ze kan bijna alles wat een lijst kan, maar bevat documenten in plaats van data-records.

## Lijst vs. bibliotheek
| [[SharePoint list]] | Document library |
|---|---|
| Bevat **data-records** (items) | Bevat **bestanden** |
| Kolommen = velden | Kolommen = **[[Metadata]]** van het document |

## Waarom beter dan bijlagen mailen?
Met documenten in een bibliotheek is er **één enkele versie van de waarheid**: iedereen werkt op hetzelfde bestand, met versiegeschiedenis.

## Metadata
- Voeg betekenisvolle kolommen toe (bv. *Topic*: News/Strategy) zodat mensen documenten makkelijk terugvinden via zoeken, filters en views.
- Maak de belangrijkste kolommen **verplicht**, anders laden gebruikers documenten op zonder metadata.
- Zie [[Mappen vs. metadata]].

## Bibliotheekinstellingen
Via **Library settings → Versioning settings**:
- [[Content approval]] verplichten voor publicatie.
- Werken met **drafts** (minor versions) afdwingen.
- Bepalen wie drafts mag zien (*Draft item security*).
- **Check-out** verplichten voor je mag bewerken.
Zie [[Versiebeheer]].

## In Teams
De bibliotheek *Documents* van een [[Teams-connected site]] bevat de bestanden van het team, met een submap per standaardkanaal.
