# Custom engine agent

> Een agent gebouwd met Copilot Studio **Full**, met een eigen orchestratie, kennis en vaardigheden, die niet op Microsoft Copilot als kern draait en ook op andere platformen/kanalen kan lopen.

## Kenmerken
- Eigen **orchestratie** (klassiek of [[Generative orchestration|generatief]]).
- [[Topics (Copilot Studio)|Topics]], [[Tools (Copilot Studio)|tools]], flows, eigen kennisbronnen (SharePoint, Dataverse, ERP, CRM, ...).
- Te publiceren op meerdere **kanalen** (website, Teams, ...).
- Voor **complexere** toepassingen.

## Lite vs. Full
| | Lite ([[Declarative agent]]) | Full (custom engine agent) |
|---|---|---|
| Kern | Microsoft 365 Copilot | Eigen engine |
| Gebruikers | Eindgebruikers | Makers/developers |
| Mogelijkheden | Instructies, kennis, prompts | + topics, tools, flows, kanalen, instellingen |
| Infrastructuur | Beheerde SaaS | Beheerde SaaS (Copilot Studio) of eigen (Azure AI Studio) |

## Licentie in de les
- Copilot Studio vraagt een **trial**: je meldt je individueel aan met je tenant-mailadres.
- De trial duurt **30 dagen** (te verlengen); een agent blijft nog tot 90 dagen na het verlopen werken.
- **Beperkingen**: strikte limieten op het aantal verzoeken per minuut/uur (kan een "agent unavailable"-fout geven), **niet publiceren**, geen geavanceerde functies, enkel voor testen en leren.
