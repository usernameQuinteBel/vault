# Global admin

> De rol met de meeste rechten in een tenant: volledige controle en toegang tot alle admin centers.

## In het project
Alle teamleden krijgen deze rol, zodat iedereen alles kan instellen (sites, Teams, Power Platform-environments, ...).

Een global admin kan ook altijd zijn rol in een Power Platform-[[Environment]] **verhogen naar System Administrator** – handig als je ergens geen toegang hebt.

## In een echt bedrijf
Geef deze rol aan **zo weinig mogelijk** mensen (principe van least privilege). Werk met specifieke beheerdersrollen (bv. enkel SharePoint-admin).
