# Web parts

> De bouwblokken op een SharePoint-pagina die content tonen: tekst, afbeeldingen, nieuws, evenementen, lijsten, documenten, video, mensen, links, grafieken, ...

## Belangrijk principe
**Lijsten en bibliotheken** zijn de **databronnen** (waar info en documenten bewaard worden). **Web parts** zijn de manier om die data te **tonen** op een pagina.

## Veelgebruikte web parts
| Web part | Doet |
|---|---|
| **Hero** | Grote tegels met afbeelding en link bovenaan een pagina (bv. 3 uitgelichte artikels) |
| **News** | Nieuwsberichten (o.a. als *filmstrip*) |
| **Events** | Agenda met evenementen |
| **Quick links** | Snelle links (bv. naar kanalen of andere sites) |
| **List** | Toont een [[SharePoint list]], met een gekozen [[SharePoint views|view]] |
| **Document library** | Toont een bibliotheek |
| **Highlighted content** | Toont dynamisch content op basis van filters (bv. documenten met *Topic = News*) |
| **Quick chart** | Eenvoudige grafiek |
| **People** | Profielen van personen (bv. supportteam met rollen) |
| **Text / Image / Video (Stream)** | Basiscontent |
| **Microsoft Forms** | Formulier inbedden |

## Werkwijze
1. Pagina in **Edit**-modus zetten.
2. Op **+** klikken in een sectie → web part kiezen.
3. In het eigenschappenpaneel de bron en weergave instellen.
4. **Republish** om de wijzigingen zichtbaar te maken.
