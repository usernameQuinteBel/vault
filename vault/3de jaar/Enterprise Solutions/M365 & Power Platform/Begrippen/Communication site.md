# Communication site

> Een SharePoint-site om informatie uit te zenden naar een breed publiek: weinig mensen maken de content, veel mensen lezen ze.

## Kenmerken
- Ideaal voor een **intranet**, nieuws, beleid, evenementen, productinfo.
- Veel functies om de site **visueel aantrekkelijk** te maken (hero web part, afbeeldingen, thema, header).
- **Geen koppeling** met een [[Microsoft 365 group]] – je beheert rechten rechtstreeks op de site.
- Wordt vaak geregistreerd als [[Hub site]].

## Aanmaken
1. SharePoint → nieuwe site → **Communication site**.
2. Sjabloon *Standard communication* kiezen.
3. Via **Settings → Change the look → Header** het uitzicht aanpassen (layout, logo).

## Voorbeeld
**Contoso Electronics** in de les: communication site die als hub het intranet vormt – zie [[Oefening 2.1 - Hub site Contoso Electronics]].
