# Azure

> Het cloudplatform van Microsoft voor infrastructuur, databanken, AI-diensten en eigen softwareontwikkeling – de "code first"-kant van de Power Platform.

## Rol tegenover de Power Platform
- De Power Platform **draait** op Azure (wereldwijde datacenters, uptime-garantie).
- Pro developers **breiden** oplossingen uit met Azure-diensten: Functions, Logic Apps, Bot Service, Cognitive/AI-diensten, IoT Hub, ...
- Voor complexe AI-agents is er Azure AI Foundry / Azure AI Studio – zie [[Copilot Studio]].
