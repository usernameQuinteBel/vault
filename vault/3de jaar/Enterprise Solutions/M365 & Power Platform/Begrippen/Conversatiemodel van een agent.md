# Conversatiemodel van een agent

> Een volledig gesprek met een agent combineert drie lagen: zelf geschreven topics, door AI gegenereerde antwoorden, en escalatie naar een mens.

## De drie lagen
1. **Authored topics** – de organisatie houdt controle over **kritieke** onderwerpen door eigen processen en workflows te ontwerpen.
2. **Generated responses** – generatieve AI beantwoordt op grote schaal de vragen die minder complex of repetitief zijn.
3. **Escalation** – kan de agent het gesprek niet aan, dan gaat het naar een **menselijke** medewerker (live agent hand-off, omnichannel).

## Hoe generatieve AI het bouwen van bots veranderde
| Vroeger (klassiek, bv. Azure Bot Framework) | Nu (Copilot Studio met generatieve AI) |
|---|---|
| Voor **elke** mogelijke vraag manueel een topic bouwen | Kennisbronnen en API's koppelen; AI doet de rest |
| Duizenden zinnen annoteren om een eigen taalmodel te trainen | Krachtig taalmodel inbegrepen, geen training nodig |
| Topics in code schrijven, infrastructuur hosten en beheren | Volledige SaaS, geen infrastructuur |
| Bij elke inhoudswijziging de bot in code aanpassen | Bron aanpassen volstaat |
| Veel gemiste of geëscaleerde gesprekken | Enkel bedrijfskritische topics nog manueel, met hulp van Copilot |

## Platform
Copilot Studio draait op de Power Platform/Azure: beveiliging, identiteitsbeheer, DLP, compliance (ISO 27001, ...), monitoring, usage analytics en een CoE-aanpak voor [[Governance]].
