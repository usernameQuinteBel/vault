# SharePoint pages

> Een SharePoint-site bestaat uit pagina's; elke pagina bestaat uit secties; elke sectie bevat web parts.

## Hiërarchie
```
Site
└── Pagina (bv. Home, Working@Contoso)
    └── Sectie (bv. 1 kolom, 2 kolommen, 3 kolommen)
        └── Web part (bv. Hero, News, Events, List, Text, Image)
```

## Pagina's
- De **homepage** is de startpagina; je kan ze bewerken met *Edit*.
- Nieuwe pagina via **New → Page**, leeg of op basis van een **sjabloon** (bv. *Product News*).
- Voeg de pagina toe aan de **navigatie** zodat mensen ze vinden.
- Pagina's kan je ook laten genereren/herschrijven met AI (Copilot), zoals in de oefeningen.

## Secties
Een sectie bepaalt de **layout** (aantal kolommen, achtergrond). Je stapelt secties onder elkaar.
