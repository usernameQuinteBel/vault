# AI agent

> Een AI-systeem dat een bedrijfsproces (of een deel ervan) ondersteunt of overneemt: het beantwoordt vragen op basis van kennis, en kan via tools ook acties uitvoeren in andere systemen.

## Bouwstenen van een agent
- **Instructies** – rol, taak, regels – zie [[Agent-instructies]].
- **Kennis** – bronnen waarop antwoorden gebaseerd zijn – zie [[Kennisbronnen (Copilot Studio)]].
- **Acties / tools** – iets doen in andere systemen – zie [[Tools (Copilot Studio)]].
- **Triggers** – wanneer de agent in actie komt (een vraag, of een gebeurtenis).

## Voorbeelden per doelgroep
| Doelgroep | Voorbeeld | Typische vraag |
|---|---|---|
| **B2C** (klanten) | Klantenservice | Hoe stuur ik een product terug? |
| B2C | Productadvies op basis van de website | Past deze laptop in mijn rugzak? |
| **B2B** (bedrijven) | Leverancierscommunicatie | Wat is de status van onze laatste bestelling? |
| B2B | Leads kwalificeren en doorsturen naar de juiste verkoper | Wat zijn jullie prijzen voor grote hoeveelheden? |
| **B2E** (medewerkers) | HR – onboarding via ERP/HR-systemen | Start de onboarding voor een nieuwe collega. |
| B2E | Onkostenbeheer | Geef de openstaande onkosten van deze week. |
