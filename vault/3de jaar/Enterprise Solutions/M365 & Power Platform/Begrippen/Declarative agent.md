# Declarative agent

> Een agent gebouwd met Copilot Studio **Lite**, die Microsoft 365 Copilot als kern gebruikt en die enkel afbakent met eigen instructies, voorgestelde prompts, kennisbronnen en acties.

## Kenmerken
- Draait **op Copilot** (gebruikt dezelfde orchestratie en modellen).
- Je "verklaart" (declareert) alleen wat de agent moet doen: instructies, kennis, prompts.
- Ideaal voor **eenvoudige, afgebakende** toepassingen: kennis opzoeken, één specifieke taak.
- Gebouwd door eindgebruikers, zonder code.

## Beperkingen (gratis licentie)
- Als kennisbron enkel **publieke websites** (max. 4 URL's).
- Met een betaalde licentie: SharePoint-bestanden/-mappen/-sites, documenten, Teams-kanalen.
