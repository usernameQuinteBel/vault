# SharePoint views

> Een view is een opgeslagen manier om een lijst of bibliotheek te tonen: welke kolommen, welke filter, sortering en groepering.

## Voorbeelden
- *All items* (standaard).
- *Group by department* – vacatures gegroepeerd per afdeling.
- *In progress* – enkel issues die nog niet afgewerkt zijn (gebruikt in de List web part op een homepage).
- In een bibliotheek: groeperen op een metadata-kolom → geeft hetzelfde resultaat als mappen.

## Hoe maak je er een?
1. Open de lijst.
2. Filter, groepeer of sorteer via de kolomkoppen.
3. Kies **Save view as** → geef een naam.

## Gebruik
- In de **List web part** kies je welke view getoond wordt.
- Views zijn niet hetzelfde als [[Dataverse views]], maar het idee is gelijk.
