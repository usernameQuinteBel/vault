# Opslag in Microsoft 365

> Microsoft 365 heeft drie plaatsen om documenten op te slaan, elk met een ander doel: OneDrive (persoonlijk), Teams (samenwerken in project) en SharePoint (georganiseerde, gecontroleerde opslag).

## Overzicht
| | [[OneDrive]] | [[Microsoft Teams]] | [[SharePoint]] |
|---|---|---|---|
| **Voor** | Persoonlijk werk | Project- en teamwerk | Organisatie / afdeling |
| **Delen** | Met specifieke personen | Met teamleden | Via robuust rechtenbeheer |
| **Focus** | Eigen bestanden, offline sync | Realtime samenwerken, vergaderen, chatten | Info-strategie, datamanagement, **finale gecontroleerde documenten** |
| **Waar fysiek?** | Persoonlijke site | In de gekoppelde SharePoint-site | SharePoint-sites |

SharePoint kent twee varianten:
- **Organisatiebreed** via [[Communication site]]s.
- **Teamgericht** via [[Team site]]s, eventueel gekoppeld aan een Teams-kanaal.

## Vuistregel
- Werk je alleen aan een draft → OneDrive.
- Werk je samen in een project → Teams (kanaal).
- Is het definitief en voor een breder publiek → SharePoint-bibliotheek met [[Metadata]] en [[Versiebeheer]].
