# Microsoft Graph

> De centrale API van Microsoft 365: één toegangspunt tot data uit alle diensten – mails, agenda's, bestanden, gebruikers, groepen, Teams-berichten, ...

## Waarom belangrijk?
- Eén API in plaats van een aparte per dienst.
- Data blijft binnen de M365 service boundary.
- Toegang volgt de **bestaande rechten** en het beveiligingsbeleid (bv. uit [[Microsoft Entra ID]]).
- [[Microsoft 365 Copilot]] gebruikt Graph om context op te halen ([[Grounding]]).
- Developers kunnen er eigen apps mee bouwen die M365-data gebruiken.
