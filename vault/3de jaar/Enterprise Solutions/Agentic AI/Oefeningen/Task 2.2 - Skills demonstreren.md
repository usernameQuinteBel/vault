# Task 2.2 - Skills demonstreren

> Toon het gebruik van een [[Skill]] op elk van de twee cases uit Task 2.1 (PowerShell-script en interview) – een andere skill per case.

**Deadline:** 18 okt 2026

## Wat moet je doen?
Per case:
- Beschrijf de skill en **waarom** je ze koos/installeerde.
- Toon de **meerwaarde**: wat verandert er als je de eisen van Task 2.1 opnieuw uitvoert met de skill?
- Toon de **resultaten**.
Upload de uitleg, de resulterende bestanden, de skill(s) en de export van het gesprek.

## Hoe installeer je een skill in OpenCode?
- Plaats de map in `.opencode/skills/<naam>/SKILL.md` (project) of de globale skills-map.
- Of laat de agent een skill uit een repo installeren.
- Controleer dat de agent de skill laadt (skill tool call in het gesprek).

## Ideeën
- PowerShell: een skill voor scripting best practices/logging, of een code-review-skill.
- Interview: een skill voor procesanalyse, BPMN, of een "grilling"/vragen-skill (zoals die van Matt Pocock).
