# Module 1 - Definitions, terms & prompting

Basisbegrippen rond LLM's: wat een model is, hoe tokens en het prijsmodel werken, waarom output niet-deterministisch is, hoe je een goede prompt schrijft (Anthropic) en wat NotebookLM is.

## Leerdoelen (examenstof 📚)
- 📚 De termen 1–14 van de [AI Coding Dictionary](https://www.aicodingdictionary.com/?term=ai) kennen en uitleggen: AI, Model, Parameters, Training, Inference, Effort, Token, Next-token prediction, Non-determinism, Model provider, Harness, Model provider request, Input tokens, Output tokens.
- 📚 Tokens in detail uitleggen, samen met encoding, decoding en hoe het prijsmodel van LLM's werkt.
- 📚 Een effectieve en efficiënte volledige prompt maken volgens de lessen van Anthropic.
- 📚 Uitleggen wat Gemini NotebookLM is en waarvoor je het gebruikt.
