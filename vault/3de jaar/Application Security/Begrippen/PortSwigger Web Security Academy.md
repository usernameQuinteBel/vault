# PortSwigger Web Security Academy

> Een **gratis online leerplatform** van de makers van [[Burp Suite]], met theorie én **labs**: tijdelijke, bewust kwetsbare webapps die je **mag** aanvallen. Hier oefen je elk hoofdstuk praktisch.

## Hoe werkt het?
- Gratis account nodig. Elke lab heeft een "Access the lab"-knop, draait op een **eigen tijdelijke instantie** en kan je resetten; niks dat je doet is blijvend.
- De toestemming geldt **enkel** voor die lab-instanties. **Al de rest blijft verboden** zonder toestemming van de eigenaar (de kernregel van [[Introductie Application Security]]).

## Hoe je er het meeste uit haalt
- Werk de labs **in volgorde** en laat ze aansluiten bij de theorie.
- **Zoek geen oplossingen online**: de **redenering** naar de payload is het leerdoel, niet de payload zelf. Kopieer je een antwoord, dan leer je niets.
- **Voorspel** elk resultaat vóór je verstuurt; faalt een lab, leg jezelf dan uit **welke aanname** fout was vóór je iets verandert.
- Gebruik [[Burp Suite]] (vooral Repeater) om je payloads te versturen en responsen te vergelijken.

Handige referentie bij SQLi: de **SQL injection cheat sheet** (syntax per databasetype). Startpunt: https://portswigger.net/web-security/ — overzicht per hoofdstuk: [[PortSwigger labs per onderwerp]].
