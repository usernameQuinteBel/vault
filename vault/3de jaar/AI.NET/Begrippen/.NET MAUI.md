# .NET MAUI

> **.NET Multi-platform App UI**: Microsofts framework om met **één C#-codebase** en **XAML** native apps te bouwen voor **Android, iOS, macOS en Windows**.

## Wat is het?
.NET MAUI is de opvolger van **Xamarin.Forms**. Je schrijft de UI één keer in [[XAML]] (of C#) en de logica in C#; MAUI vertaalt jouw controls naar de **echte native controls** van elk platform. Een `Button` wordt dus een Android-`Button`, een iOS-`UIButton` en een WinUI-`Button`. Daardoor voelt de app op elk toestel "thuis", in tegenstelling tot frameworks die alles zelf tekenen.

## Hoe zit het in elkaar?
- **Eén project, meerdere targets**: in `Platforms/` zit per platform een klein stukje specifieke code (bv. `AndroidManifest.xml` voor permissies).
- **Gedeelde resources**: afbeeldingen, fonts en kleuren in `Resources/` worden automatisch per platform geschaald/omgezet.
- **Opstart** via `MauiProgram.cs` (zie [[MAUI projectstructuur]]).
- **Navigatie** via [[Shell en TabBar|Shell]].

## Wat kan het?
- Native UI en toegang tot toestelfuncties (camera, GPS, opslag) via **.NET MAUI Essentials** (bv. `MediaPicker` voor de camera in SafariSnap).
- Werken met [[MVVM]], [[Dependency Injection]] en [[Data binding]] — de architectuur die je in dit vak leert.
- Hot reload tijdens ontwikkelen (XAML en .NET).

## Waarom MAUI in dit vak?
| | Aparte native apps | .NET MAUI |
|---|---|---|
| Talen | Kotlin + Swift + C# | enkel C# + XAML |
| Codebase | 3 aparte | 1 gedeelde |
| Kennis hergebruiken | weinig | je C#/.NET-kennis uit vorige jaren |
| Azure AI aanspreken | per platform | één keer, in een gedeelde service |

## Installatie
Visual Studio met de **.NET Multi-platform App UI**-workload (of VS Code + de .NET MAUI-extensie). Android: een emulator of toestel met USB-debugging. iOS/macOS vereist een Mac.
