# UI UX

Vak uit het **3de jaar** (3APP). Je leert gebruikers analyseren, schermen ontwerpen in **Figma** en een ontwerp zo uitwerken dat een developer het vlot kan bouwen.

> *"As a developer, you don't just build software — you build experiences."*

## Waarom dit vak voor een developer?
- Zonder goede UX haakt de gebruiker af, hoe goed de code ook is.
- Elk app-project wordt (onrechtstreeks) beoordeeld op de interface.
- UI/UX vertaalt technische functies naar een begrijpelijke ervaring: de brug tussen code en gebruiker.
- Je begrijpt de keuzes van designers en kan met hun tools werken.
- Bedrijven zoeken developers met oog voor design, gebruiksvriendelijkheid en toegankelijkheid. Met AI die code schrijft ligt die lat hoger.

## Leerdoelen
- De behoeften van gebruikers analyseren en vertalen naar een functioneel UX-concept op basis van gangbare UX-principes.
- In Figma visueel aantrekkelijke en toegankelijke prototypes ontwerpen op basis van een gebruikersflow en UI-principes (hiërarchie, contrast, consistentie).
- Een ontwerp uitwerken en presenteren zodat het overdraagbaar is aan stakeholders (ook developers), met een design system.

## Evaluatie
- **Groepsopdracht 50 %** + **individuele opdracht 50 %**.
- Minder dan 50 % op één van de twee → maximaal **9/20** op het hele vak.
- Permanente evaluatie: actieve aanwezigheid en deelname tellen mee.
- Lessen zijn werkcolleges: korte theorie, daarna zelf doen. Feedback krijg je van docent én medestudenten, en je geeft ook zelf feedback.
- Contact buiten de les: MS Teams (voorkeur) of e-mail. Materiaal op Canvas (slides, FigJam-borden, externe bronnen). Een **Figma Education account** is verplicht.

> *"The only way to do design is to do design."* — Alan Cooper
